# PaperS3 Clear Message Cache Design

**Goal**

在设置页提供一个设备端本地“清空消息缓存”入口，方便反复测试消息分页与局部刷新，不影响后端数据或其他设备配置。

**Design**

设置页新增一行 `清空消息缓存`。点击后立即执行，不增加确认页，也不引入新的页面状态，优先保证测试流畅。

清空范围只限设备本地消息状态：
- `messages[]`
- `messageCount`
- `messagePage.currentPageIndex`
- `lastMessageCursor`

同时保留：
- Wi‑Fi 配置
- EPD 刷新模式
- 拉取间隔
- 任务与积分数据

执行后立即持久化 `state`，并更新状态文案为“消息已清空”。如果当前正在消息页，消息列表应变成空态；从设置页触发时直接留在设置页即可。

**UI**

设置页行数从 `7` 增加到 `8`，顺序调整为：
1. 插电拉取间隔
2. 电池拉取间隔
3. 刷新模式
4. Wi‑Fi 配置
5. 手动同步
6. 刷新实验
7. 清空消息缓存
8. 返回今日

**Testing**

- 设置页可见新按钮
- 点击后本地消息数清零
- 重启后仍保持空消息状态
- 不影响 Wi‑Fi、刷新模式和任务数据
