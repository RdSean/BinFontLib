# PaperS3 钉钉消息入口设计文档

**Date:** 2026-04-07
**Repo:** `BinFontLib`
**Branch:** `papers3-binfont-demo`

## 目标

移除当前 MVP 中的屏保功能，将原 `屏保` tab 改为 `消息` 入口。设备不直接对接钉钉，而是通过一个简单的中转服务接口拉取只读消息列表，让钉钉侧复杂性留在服务端。

第一阶段目标不是聊天终端，而是一个低干扰、可近实时查看通知的电子纸消息页。

## 产品决策

- 删除 `屏保页`
- 底部 tab 从 `今日 / 成长 / 屏保 / 配置` 改为 `今日 / 成长 / 消息 / 配置`
- 设备端只读，不支持回复
- 设备端不直接调用钉钉机器人接口
- 消息通过中转服务拉取
- 轮询频率可配置
- 默认轮询频率：
  - 插电：`2 秒`
  - 电池：`10 秒`

## 为什么不用设备直连钉钉

- 设备仍然需要轮询，功耗不会因为“直连钉钉”而本质下降
- 钉钉机器人鉴权、消息格式、错误处理和未来扩展更适合放在服务端
- 设备端只保留“拉消息列表”的简单边界，更符合当前 `sync` 架构和嵌入式代码复杂度控制

## 架构边界

### 设备端职责

- 根据电源状态按配置频率轮询消息接口
- 缓存最近消息
- 展示消息列表和消息详情
- 提供消息轮询配置
- 本地保存消息游标、消息缓存和轮询配置

### 中转服务职责

- 接收或整理钉钉机器人消息
- 提供设备友好的简单读取接口
- 做消息去重、格式转换、时间排序和游标管理
- 隐藏钉钉鉴权和复杂协议细节

## 页面结构

### 1. 消息列表页

- 替换原 `屏保页`
- 显示最近消息，按时间倒序
- 每条消息显示：
  - 标题
  - 1 到 2 行摘要
  - 时间
  - 未读标记
- 列表支持滚动查看

### 2. 消息详情页

- 点击消息列表项进入
- 显示完整标题、时间、正文
- 支持纵向步进滚动查看长文本
- 保持电子纸友好的低频翻页体验，不做手机式连续惯性滚动

### 3. 配置页扩展

- 新增 `插电拉取间隔`
- 新增 `电池拉取间隔`
- 显示最近一次消息拉取状态

## 交互原则

- 列表页优先使用“选择项移动 + 翻页”而不是连续滚动
- 详情页使用“整屏步进滚动”
- 拉取新消息时尽量只刷新必要区域
- 拉取失败不清空本地消息
- 页面反馈保持克制，只显示简短状态

## 消息数据模型

建议设备端最小字段：

- `message_id`
- `title`
- `body`
- `sent_at`
- `source`
- `read`

建议设备端额外状态：

- `message_count`
- `selected_message_index`
- `message_scroll_offset`
- `last_message_cursor`
- `poll_interval_charging_sec`
- `poll_interval_battery_sec`
- `last_message_sync_at`

## 拉取接口建议

设备端只依赖简单接口，例如：

`GET /api/device/messages?device_id=<id>&since_id=<cursor>`

返回结构建议包含：

- `messages`
- `next_cursor`
- `server_time`
- `has_more`

设备无需关心钉钉原始 payload。

## 轮询策略

- 设备启动后加载消息缓存和轮询配置
- 根据当前是否充电选择轮询间隔
- 到达时间后触发一次消息拉取
- 拉取成功后合并消息、去重、更新游标并保存本地
- 拉取失败时保留原消息缓存
- 电源状态变化后重新采用对应轮询间隔

## 本地存储

新增或扩展本地持久化以保存：

- 消息列表缓存
- 消息游标
- 未读状态
- 轮询间隔配置
- 最近一次消息拉取状态

## 与现有模块的关系

- `render` 继续负责纯显示：消息列表排版、消息详情排版、滚动位置渲染、状态栏更新
- `font` 继续负责中文显示
- `sync` 负责网络消息拉取边界
- 业务层只描述当前消息状态、选中项和滚动位置

## 第一阶段不做的内容

- 不回复钉钉消息
- 不上传图片、附件或语音
- 不做 Markdown 富文本
- 不做长连接或 WebSocket
- 不做消息发送确认、互动按钮或复杂动作卡片

## 验收标准

- `屏保` tab 被移除并替换为 `消息`
- 设备能从本地缓存显示消息列表
- 设备能按电源状态使用不同拉取间隔
- 默认值为插电 `2 秒`、电池 `10 秒`
- 消息详情页支持长文本滚动查看
- 拉取失败时消息列表不丢失
- 配置页可查看和修改轮询间隔
